## Learning Path

### Week 1: Basics
- [ ] Read tutorial/introduction
- [ ] Understand registers (AX, BX, CX, DX)
- [ ] Write first MOV program
- [ ] Complete Challenge 1-3

### Week 2: Arithmetic
- [ ] Master ADD, SUB, MUL, DIV
- [ ] Understand postfix notation
- [ ] Write multi-step calculations
- [ ] Complete Challenge 4-7

### Week 3: Input/Output
- [ ] Practice INPUT/OUTPUT
- [ ] Build interactive programs
- [ ] Complete Challenge 8-10

### Week 4: Advanced
- [ ] Work around limitations
- [ ] Build complex sequences
- [ ] Complete Challenge 11-15
- [ ] Build a capstone project

### Month 2+: Projects
- Temperature Converter (full suite)
- Calculator application
- Number sequence library
- Educational tutorial series
